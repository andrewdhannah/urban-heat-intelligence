# Decision Summary

Luna is an isolated, framework-free challenger that makes the measured geographic field primary, communicates near-tie uncertainty directly, separates decision evidence from context, and provides progressive Brief/provenance disclosure. It preserves the existing API and does not touch the incumbent dashboard or analytical backend.

**Recommendation:** KEEP AS EXPERIMENT until independent QA confirms browser behavior, visual quality, and the backend's distinct GIS unavailable state. Then consider **SYNTHESIZE** or promote only through the documented owner-controlled checklist.
