# Product Intent

## Audience
Municipal operations, urban planning, heat-response analysts, public-sector decision makers, and a first-time hackathon judge.

## User objective
Answer within seconds: **Where should Phoenix prioritize a cooling intervention this afternoon?** Then make the evidence, uncertainty, and source roles inspectable.

## Hackathon objective
Tell a credible three-minute story: Phoenix → measured FortyGuard field → comparable candidates → local context → brief → provenance.

## Principles
1. Geography before dashboards: the map is the primary analytical surface.
2. Evidence before confidence: measured, derived, contextual, and unavailable states are explicit.
3. Near-ties are insight, not visual noise.
4. Investigation, not unsupported prescription.
5. Replay is reproducibility; Live is latest available—not interchangeable modes.
6. Progressive disclosure: glanceable, analytical, audit layers.
7. Every map claim has a textual alternative.
