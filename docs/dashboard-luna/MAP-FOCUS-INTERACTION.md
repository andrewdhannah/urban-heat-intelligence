# Map Focus Interaction

Successful payloads add `has-result`, compressing the introduction and expanding the map. The `Focus map` control enters a reversible full-width working state; the answer rail becomes a compact overlay. Legend, observation time, mode, candidate markers, near-tie disclosure, and evidence control remain available. Exit restores the story layout. Reduced motion avoids smooth scrolling and meaningful transitions. Mobile uses a stacked map-first layout and does not force the desktop overlay treatment.
