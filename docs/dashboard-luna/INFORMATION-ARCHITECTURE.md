# Information Architecture

## Hierarchy

Header → decision question → observation/mode → measured map → answer rail → candidate comparison → brief/context → audit evidence.

## Workflow

1. Replay auto-runs.
2. Read answer and observation time.
3. Use map to understand spatial concentration.
4. Compare up to three deterministic candidates.
5. Interpret near-tie without false precision.
6. Inspect Phoenix GIS context and environmental context.
7. Open Brief for claim-level narrative.
8. Open evidence drawer for canonical steps and actual events.

## Responsive structure

- Desktop: map and answer rail side-by-side; candidate cards in three columns.
- Tablet: map above answer rail; lower sections remain two columns where safe.
- Mobile: map above rail; candidates become a single keyboard-accessible list; brief and context stack; audit drawer becomes full-width.
