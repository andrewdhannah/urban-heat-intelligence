# Luna V2 — Map Story + Grounded Analyst

V2 preserves the frozen Luna information architecture while making the loaded measured field the dominant result surface. Before resolution, the question composer and introduction lead. After a successful answer, `body.has-result` compresses the introduction and expands the measured map to the working viewport. `Focus map` hides supporting sections temporarily, keeps mode, legend, markers, near-tie read, and evidence access visible, and is reversible.

The question field is a deterministic grounded analyst, not a chatbot. A registry maps bounded intent families to answer builders reading the current payload, source-role disclosure, optional navigation action, and state-aware follow-ups. Unsupported intervention-efficacy questions are explicitly declined.

No ranking, provider, mode, or evidence semantics changed. Replay environmental parameters remain representative context and are shown once in the answer rail.
