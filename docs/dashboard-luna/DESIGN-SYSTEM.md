# Design System

## Direction
Warm mineral paper and editorial type create civic seriousness; deep blue anchors decision evidence; terracotta and amber indicate measured heat without importing unsupported danger categories.

## Tokens

Tokens live in `app/dashboard-luna/css/tokens.css`: ink, muted text, paper/surfaces, line, blue decision palette, teal context palette, amber/terracotta thermal palette, error state, focus ring, spacing scale, radii, shadows, Manrope sans and Georgia serif.

## Components

- Topbar and Data Mode switch
- Decision intro/question form
- Observation card
- Measured map panel and cell detail
- Answer rail
- Candidate comparison card
- Brief claim section
- Context row
- Evidence timeline drawer

Source roles always use labels, position, and copy in addition to color. Focus uses a visible high-contrast ring. Motion is optional and reduced-motion compatible.
