# Story Source Registry

- **FortyGuard** — primary measured thermal evidence; determines thermal ordering.
- **Phoenix GIS** — local canopy and park context; `used_in_decision=false`.
- **NWS** — supplemental current/forecast context; never re-ranks.
- **USGS NLCD, NOAA/NCEI, Maricopa County, approved local history** — dormant attachment points only. They are not rendered or suggested until integrated and qualified.

Story order: decision → measured field → thermal cluster → local physical context → current weather → historical context (only when active) → Urban Heat Brief → provenance.
