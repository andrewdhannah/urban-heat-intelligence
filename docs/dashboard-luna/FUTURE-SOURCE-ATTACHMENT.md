# Future Source Attachment

Future sources must arrive as authorized normalized context sections with provider, source type, effective period, retrieved time, availability, and `used_in_decision` status.

- **NOAA/NCEI:** historical event timeline or map layer, explicitly historical and never mixed into a current Replay/Live observation without temporal labeling.
- **USGS NLCD:** impervious-surface context layer, reference-year labeled; cannot imply causality or intervention efficacy.
- **Maricopa County:** public-health context section with geography/time and aggregation caveats; not a thermal rank.
- **Historical/community context:** attributable narrative/context adapter with clear provenance and no unsupported causal claim.

The current Luna UI has a context panel and Brief claim model that can accept these sections without changing the FortyGuard thermal render path.
